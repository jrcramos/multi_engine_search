## 🛠️ Installation

### Quick Installation (Developer Mode)

#### Step 1: Download the Extension
```bash
git clone https://github.com/jrcramos/multi_engine_search.git
cd multi_engine_search
```

Or download as ZIP from GitHub and extract it.

#### Step 2: Enable Developer Mode
- Open Chrome/Edge and navigate to:
  - Chrome: `chrome://extensions/`
  - Edge: `edge://extensions/`
- Toggle **"Developer mode"** in the top right corner

#### Step 3: Load the Extension
1. Click **"Load unpacked"**
2. Navigate to and select the `multi_engine_search` folder
3. The extension icon will appear in your toolbar ✅

#### Step 4: Pin for Easy Access (Recommended)
- Click the 🧩 extensions puzzle icon in your browser toolbar
- Click the 📌 pin icon next to "Multi-Engine Search Pro"

> 🎉 **Done!** The extension is now ready to use. Click the icon to start searching!

## 🎯 Usage

### Basic Search Workflow
1. 🖱️ **Click the extension icon** in your browser toolbar
2. ⌨️ **Enter your search term** in the input field (e.g., "machine learning algorithms")
3. ☑️ **Select search engines** - Choose from organized categories:
    - **General**: Google, Bing, DuckDuckGo, Brave
    - **Privacy**: Startpage, Qwant, Mojeek, Presearch, Kagi
    - **Academic & Research**: Google Scholar, arXiv, Semantic Scholar, Sci-Hub, LibGen
    - **SearXNG (Uncensored & Meta)**: SearXNG (PaulGo), SearXNG (Tiekotter), SearXNG (Linxx), SearXNG (Priv AU), SearXNG (Iceland)
    - **Alternative**: Yandex, Yandex (Alt), You.com, Yep, Lilo, Reddit, GitHub
    - **Specialized**: Rutracker, Anna's Archive, BTDigg
4. 🚀 **Execute search** - Press Enter or click "Search on X engines"
5. 📑 **View results** - Each engine opens in a separate tab

### Quick Actions & Tips
- **📋 Select All Engines**: Click "Select All" or use `Ctrl+A` / `Cmd+A` for comprehensive research
- **🗑️ Clear All Selections**: Click "Clear All" to start fresh
- **✨ Clear Search Term**: Click "Clear" button or press `Escape`
- **❌ Close Extension**: Press `Escape` when search field is empty

### Smart Features in Action
- **Memory**: Your last search term is remembered during the session
- **Persistence**: Selected engines are saved between browser sessions
- **Dynamic Button**: Button text updates to show "Search on X engines" based on your selection
- **Validation**: Get instant feedback if no search term or engines are selected

## 🐛 Troubleshooting

### Common Issues

**Extension doesn't appear after installation**
- Ensure Developer Mode is enabled
- Try refreshing the extensions page
- Check that all files are in the correct directory

**Search doesn't work on some engines**
- Some specialized engines may require user accounts
- Check if the search engine URL has changed
- Verify your internet connection

**Extension popup doesn't open**
- Check Chrome's extension permissions
- Try disabling and re-enabling the extension
- Look for error messages in Chrome's developer console

**Searches open too many tabs**
- Review your selected engines before searching
- Use "Clear All" to deselect all engines
- Consider using fewer engines for routine searches

### Getting Help

1. **Check Browser Console**: Open Developer Tools (F12) for error messages
2. **Verify Permissions**: Ensure the extension has necessary permissions
3. **Update Chrome**: Make sure you're using a recent Chrome version
4. **Report Issues**: Create an issue on GitHub with detailed information

## ❓ Frequently Asked Questions

### Does this extension collect my search data?
**No!** The extension operates entirely locally. Your searches are only sent directly to the search engines you select. We don't collect, store, or transmit any of your data.

### Will this slow down my browser?
**No.** The extension is lightweight and only activates when you click the icon. Opening multiple tabs is handled efficiently by your browser.

### Can I customize which search engines are available?
Currently, the 29 engines are built-in. Custom engine support is on our roadmap! You can contribute via GitHub if you'd like to help add this feature.

### Why do some searches open too many tabs?
You can control exactly how many tabs open by selecting only the engines you need. Use "Clear All" to deselect engines, then choose specific ones for focused searches.

### Does this work with Firefox/Safari/Opera?
Currently, the extension supports **Chrome and Edge** (Chromium-based browsers). Firefox and Safari support is planned for future releases.

### Are the specialized engines legal?
The extension simply provides links to search engines. Users are responsible for complying with their local laws and the terms of service of each search engine.
