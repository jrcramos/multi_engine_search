## Adding New Screenshots

When adding new screenshots:
1. Use descriptive filenames (e.g., `feature-bulk-select.png`)
2. Keep images reasonably sized (under 500KB when possible)
3. Use PNG format for UI screenshots
4. Update this README with descriptions of new images
