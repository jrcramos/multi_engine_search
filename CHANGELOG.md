# Changelog

All notable changes to Multi-Engine Search Pro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2024-09-27

### Added
- 🎉 **Major Release**: Complete rewrite with modern UI and enhanced functionality
- 🔍 **14 Search Engines**: Comprehensive selection across 4 categories
  - General Search: Google, Bing, DuckDuckGo, Brave
  - Privacy-Focused: Startpage, Qwant, Mojeek, Presearch  
  - Alternative: Yandex, You.com, Yep, Lilo
  - Specialized: Rutracker
- 💾 **Smart Memory System**: 
  - Session-based search term memory
  - Persistent engine preference storage
- ⚡ **Bulk Operations**: Select all/clear all engine controls
- ⌨️ **Keyboard Shortcuts**: 
  - `Ctrl+A`/`Cmd+A` to select all engines
  - `Enter` to execute search
  - `Escape` to clear or close
- 🎨 **Modern UI**: Clean, responsive interface with organized categories
- 📱 **Enhanced UX**:
  - Dynamic button text based on selections
  - Real-time validation and feedback
  - Loading states and status messages
  - Auto-close after successful search

### Technical Improvements
- ✅ **Manifest V3**: Updated to latest Chrome Extension standard
- 🔒 **Proper Permissions**: Minimal required permissions (tabs, storage)
- 🏗️ **Clean Architecture**: Modular JavaScript with clear separation of concerns
- 💻 **Modern CSS**: Flexbox layouts with smooth animations
- 🔧 **Error Handling**: Comprehensive error handling and user feedback

### Documentation
- 📚 **Comprehensive README**: Detailed installation and usage instructions
- 🤝 **Contributing Guide**: Clear guidelines for contributors
- 📄 **MIT License**: Open source license for community contributions
- 📝 **Changelog**: Version history tracking
