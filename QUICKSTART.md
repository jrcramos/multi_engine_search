# Quick Start Guide

Get up and running with Multi-Engine Search Pro in under 2 minutes! 🚀

![Multi-Engine Search Interface](screenshots/main-interface.png)

## ⚡ Super Quick Setup

### 1. Install (30 seconds)
```bash
# Download
git clone https://github.com/jrcramos/multi_engine_search.git

# OR download ZIP from GitHub and extract
```

### 2. Load in Chrome (30 seconds)
1. Open `chrome://extensions/`
2. Enable "Developer mode" (top-right toggle)
3. Click "Load unpacked"
4. Select the `multi_engine_search` folder

### 3. Start Searching (10 seconds)
1. Click the extension icon in toolbar
2. Type your search term
3. Select engines (Google + Bing are pre-selected)
4. Press Enter!

## 🎯 First Search Example

**Goal**: Research "machine learning algorithms"

1. **Open Extension**: Click the icon in your Chrome toolbar
2. **Enter Query**: Type `machine learning algorithms`
3. **Select Engines**: Keep Google and Bing checked, also check DuckDuckGo
4. **Execute**: Press Enter or click "Search on 3 engines"
5. **Results**: 3 tabs open with results from different search engines

**Result**: You now have diverse perspectives on machine learning algorithms! 🎉

## 🔥 Power User Tips (1 minute read)

### Super Fast Searching
- **Keyboard**: `Ctrl+A` selects all engines, `Enter` searches, `Escape` clears
- **Memory**: Your search terms and preferred engines are remembered
- **Categories**: Engines are organized - use privacy-focused for sensitive searches

### Smart Engine Selection
- **Research**: Use Google + Bing + DuckDuckGo + Yandex for comprehensive results
- **Privacy**: Use only Startpage + DuckDuckGo + Qwant for private searching
- **Shopping**: Use Google + Bing + You.com for product comparisons
- **International**: Include Yandex for non-English content

## 🚨 Troubleshooting (if something goes wrong)

**Extension not showing up?**
- Make sure you enabled Developer mode in chrome://extensions/
- Try refreshing the extensions page

**Can't search?**
- Enter a search term first
- Select at least one search engine
- Check your internet connection

**Too many tabs opening?**
- Use fewer search engines for routine searches
- Select engines strategically based on your needs
